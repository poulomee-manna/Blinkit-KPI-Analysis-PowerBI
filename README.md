# 📊 Blinkit KPI Analysis – Power BI

Interactive Power BI dashboard analyzing Blinkit sales KPIs, outlet performance, and product-level insights using DAX and data modeling.

---

## 📌 Project Overview

This project presents an interactive Power BI dashboard analyzing Blinkit's retail sales performance. The objective of this analysis is to evaluate key business KPIs, product performance, and outlet-level insights to support data-driven decision-making.

The dashboard provides a comprehensive view of revenue trends, order distribution, outlet performance, and category-wise sales contribution.

---

## 🎯 Business Objectives

- Analyze Total Revenue, Orders, and Average Sales  
- Identify Top 10 Performing Products  
- Evaluate Outlet Performance by Size & Location  
- Compare Sales Contribution by Product Categories  
- Understand Overall Sales Distribution Trends  

---

## 📈 Key KPIs

- Total Sales  
- Total Orders  
- Average Order Value  
- Sales by Outlet Type  
- Sales by Product Category  
- Top Products by Revenue  

---

## 🛠 Tools & Technologies Used

- Power BI  
- DAX (Data Analysis Expressions)  
- Power Query  
- Data Modeling  
- Data Cleaning & Transformation
